# LVGL Macintosh复古UI规范

## 固定条件

- 320×240横屏。
- ILI9341 SPI显示。
- 无触摸，只使用左、中、右三个实体按钮。
- 中键单击切换到下一页，中键双击切换到上一页；页面为 SYSTEM、WEATHER、MARKETS。
- 信息优先，复古外观不能牺牲状态和错误可读性。

## 已冻结视觉方向

- 主风格采用System 7：灰阶界面、经典窗口、条纹标题栏、方形控件和像素图标。
- 辅助借用System 1的高对比黑白元素，但不混入Mac OS 8/9 Platinum控件。
- 所有屏幕文本使用纯英文，不加载中文字库。
- 优先采用位图字体、自制单色图标和少量状态色，控制Flash、RAM与绘制开销。

## 方向选择记录

### 1984 Macintosh / System 1

- 纯黑白、高对比、1位图像感。
- 极简桌面、菜单栏、窗口和像素图标。
- 最节省颜色与资源，但同时显示多种状态时层级较弱。

### System 6/7

- 黑白到灰阶、条纹标题栏、经典窗口阴影和方形控件。
- Macintosh辨识度最高，适合320×240和非触摸操作。
- 已选为主风格。

### Mac OS 8/9 Platinum

- 铂金灰、立体边框、更多颜色和较密集控件。
- 信息层级丰富，但小屏幕容易显得拥挤，资源量也更大。

Mac OS 8/9仅作为对比资料，不进入组件规范。

## 三页信息结构

- UI由三个固定仪表盘页面组成，页面切换不改变网络、KVM或温控状态。
- 所有页面顶部使用老式Macintosh图标语言，显示当前页面、局域网连接、Mac连接和Windows连接；Internet只代表Wi-Fi/局域网已连接。
- `SYSTEM`页面显示ESP32运行状态、IP、客户端连接、数据来源、KVM阶段和最近错误。
- `WEATHER`页面显示当前天气、未来三天和未来五个整点。
- `MARKETS`页面显示BTC/USDT、DOGE/USDT和USD/CNY。
- 天气与行情来自客户端的dashboard快照；ESP32不直接访问互联网。
- 散热器窗口显示实际档位、目标温度和模式。内容区上方居中显示像素风扇图标，左侧用单个小数字显示推定档位`1`至`4`，右侧显示当前预设温度，下方一行显示`MANUAL`、`STANDARD`、`SILENT`或`TURBO`。
- 散热器关闭、初始化或错误时，档位位置分别显示`-`、`...`或`!`；Manual模式的目标温度位置显示`--`。
- CPU与散热器预设温度保持UNSCII点阵字体；温度数字与字母`C`之间使用独立绘制的像素圆环作为`°`，不得为了一个符号替换整组字体。
- Live Data内存占用使用20格进度条，每格5%；整条进度条必须有连续黑色矩形外框，分段绘制在外框内部。
- 底部不显示三个实体按键及其功能说明，不绘制伪软按键。

## 组件规范

- 顶部固定保留System 7风格菜单栏，以点阵图标配合极短文字显示局域网、Mac和Windows连接状态。
- 主内容使用一到两个经典窗口容器，不堆叠现代卡片。
- 在线、离线、过期、未知和冷却必须同时通过文字与图形区分，不能只靠颜色。
- 切换、继电器动作和校准提供短时状态提示。
- 动画只用于必要反馈，页面切换优先即时或极短过渡。
- 使用开源可分发字体和自制像素图标，不复制Apple专有资源。
