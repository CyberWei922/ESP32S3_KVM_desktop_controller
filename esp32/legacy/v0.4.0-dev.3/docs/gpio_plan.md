# ESP32-S3 GPIO 与三键技术路线

更新：2026-09-11。

本文记录当前固件的 GPIO 基线以及三个实体按键的预留方案。所有编号均指 ESP32-S3 的 GPIO 编号，不是开发板排针顺序号。

## 1. 当前 GPIO 分配

### LCD 已占用

| 功能 | GPIO |
| --- | ---: |
| ILI9341 SCLK | 12 |
| ILI9341 MOSI | 11 |
| ILI9341 MISO | 13 |
| ILI9341 CS | 10 |
| ILI9341 DC | 9 |
| ILI9341 RST | 14 |

以上分配已经存在于 `main/include/lcd_driver.h`，后续接入按键时不得冲突。

### 三个实体按键

| 正面位置 | 功能 | 预留 GPIO | 首批状态 |
| --- | --- | ---: | --- |
| 左侧 | 单击KVM切换、双击状态校准、长按屏幕开关 | 4 | 后续实现完整事件 |
| 中间 | LCD数据翻页 | 5 | 只预留接口，首批不执行功能 |
| 右侧 | 散热模式切换 | 6 | 后续实现完整事件 |

GPIO 4、5、6 是基于当前 LCD 使用 GPIO 9～14 后的项目预留。正式焊接前必须在实际 ESP32-S3-N16R8 开发板丝印和原理图上再次确认三脚均已引出且没有被板载外设占用；若实物板型不符，应先更新本文和固件常量，再接线。

## 2. 按键接线

三个机械轴体均按“按下接地”连接：

```text
GPIO4 ─── 左侧按键 ───┐
GPIO5 ─── 中间按键 ───┼── ESP32 GND
GPIO6 ─── 右侧按键 ───┘
```

- 轴体无正负极，任意一脚接 GPIO，另一脚接公共 GND。
- GPIO 配置为输入并启用内部上拉：未按为 HIGH，按下为 LOW。
- 外壳内短距离杜邦线首版不要求外接电阻。
- 如果实测出现干扰，每个 GPIO 可增加一只 10kΩ 电阻上拉到 3.3V；不得上拉到 5V。
- 10kΩ 上拉电阻接在 GPIO 与 3.3V 之间，不串联在按键线路中。

## 3. 固件技术路线

### 输入层

- 将三个 GPIO 常量集中定义，禁止在页面或业务代码中散落数字引脚号。
- 使用周期扫描或 GPIO 边沿通知配合软件状态机；不得在中断中直接执行 LCD、网络、DDC或继电器操作。
- 初始建议每 10 ms 采样一次，稳定约 30 ms 后才确认按下或松开，最终参数以实机手感调整。

### 事件层

输入层只产生语义事件，例如：

```text
KVM_SINGLE_CLICK
KVM_DOUBLE_CLICK
KVM_LONG_PRESS
PAGE_NEXT
COOLING_MODE_NEXT
```

- 单击与双击共用的左键需等待双击判断窗口；初始建议 300 ms。
- 长按达到阈值后只触发一次，持续按住不得重复触发。
- 中间按钮首批可以完成GPIO初始化、消抖和日志验证，但不得发布 `PAGE_NEXT` 业务事件；通过独立功能开关在后续版本启用。

### 页面层

- 后续建立统一页面管理器，维护“已注册且可用”的页面列表与当前页面索引。
- 收到 `PAGE_NEXT` 后索引循环递增，并请求一次局部或整页刷新。
- 页面切换不能清除两台电脑的最新状态，也不能重新建立 WebSocket 连接。
- 新页面通过注册加入，不修改中间按钮驱动逻辑。
- 未完成或被禁用的页面不进入循环列表。

## 4. 验证要求

- 三键分别快速和缓慢按压至少 50 次，无漏触发和重复触发。
- 左键单击、双击、长按互不误判。
- 中间按钮首批按下只产生诊断日志，不改变屏幕和系统状态。
- 后续启用翻页后，连续循环翻页至少 100 次，网络和温控任务不中断。
- ESP32 上电、复位和烧录期间，未按下的按键均保持释放状态。
