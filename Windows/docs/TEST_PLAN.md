# Windows 客户端验收计划

测试遵循“自动测试一次、真机关键路径适度验证”的原则，不要求无意义重复验收。

## 1. 完成定义

以下全部满足，Windows v1 才算完成：

- Release 构建和自动测试通过。
- 程序只有一个托盘图标，无主窗口、无控制台窗口。
- 设备 ID 重启后不变。
- 能连接 ESP32、发送合法 Hello 和每秒遥测。
- CPU 温度或传感器不可用时能正确降级，内存仍继续上报。
- 选定 X41Q 后，手动 DDC 到 6 和 7 都成功。
- Windows 收到 `target: "mac"` 后写 6 并在 5 秒内正确回包。
- DDC 失败时 ESP32 不切 USB。
- 关闭 ESP32 临时测试模式后，Mac ↔ Windows 双向完整切换成功。
- 睡眠恢复、网络断开和 ESP32 重启后能够恢复连接，不误切换显示器。

## 2. 自动测试

### 协议

- Hello 字段和 snake_case 编码完全正确。
- 有效/无效 CPU 与内存指标编码正确。
- 序号严格递增；重连会话可重置。
- 能解析两个合法 target。
- 拒绝错误版本、空 request ID、错误设备 ID、错误 action、未知 target、非文本和超长消息。
- command_result 三种组合符合 ESP32 约束。
- 协议 error 不超过 63 字节。

### 配置与状态

- 首次运行生成 `win-<guid>`，第二次读取相同 ID。
- 缺失/损坏/更高 schema 配置回到安全状态。
- 配置原子写入。
- 未选择显示器时 KVM 不能启用。
- 注册表启动项的添加、读取、删除只影响本程序键值。

### 队列与命令

- 慢网络下遥测不会无限积压，永远只保留最新待发值。
- 命令结果优先于遥测。
- 相同 request ID 连续发送两次只调用一次 DDC，并重发同一结果。
- 两个不同命令不会并行写 DDC。
- 退出和重连不会留下第二个连接循环。

### DDC 与指标

- target 到 6/7 的映射正确。
- 未选择、找不到、写失败和超时返回精确错误码。
- 所有模拟物理显示器句柄都得到释放。
- CPU 缺失不会阻止内存快照。
- 内存百分比边界在 0..100。

## 3. Windows 单机真机测试

1. 启动后确认任务栏没有窗口，只有一个托盘图标。
2. 连续启动第二次，确认没有第二个图标和第二条连接。
3. 在“目标显示器”中明确选择 X41Q。
4. 保持 KVM 关闭，分别执行手动切到 Mac 6、Windows 7，观察显示器真实切换。
5. 每个方向各测试 3 次即可；若失败再针对失败项诊断，不做无意义几十次重复。
6. 拔掉或关闭 X41Q 后测试，程序必须报 `display_not_found`，不能切另一台屏幕。
7. 关闭 KVM 后向客户端发送合法命令，确认回 `kvm_disabled`。
8. 检查日志中包含 request ID、输入值、耗时和结果，不包含每秒刷屏的遥测。

## 4. 与 ESP32 的分阶段测试

### 阶段 A：保持 Mac → Windows 测试模式

- 先修改 ESP32 的 Windows 遥测来源校验，但保持 `APP_MAC_TO_WINDOWS_TEST_MODE = 1`。
- Windows Hello 后，ESP32 顶栏 Windows 图标应常亮；断开后按现有 UI 规则闪烁。
- Windows 的 CPU 温度与内存应在 Windows 数据页显示，不能显示 `F` 或来源错误。
- 用托盘手动 DDC 验证 6/7，不触碰 USB 继电器。
- 从 Mac → Windows 完整切换一次，确认仍由 Mac 执行 DDC 7、ESP32 再切 USB；Windows 不应收到这条命令。

### 阶段 B：开启完整双向模式

- 设置 `APP_MAC_TO_WINDOWS_TEST_MODE = 0`，编译并刷写 ESP32。
- 当前在 Windows 时按左键单击：Windows 收到 `target: "mac"` → DDC 写 6 → 回成功 → ESP32 GPIO 7 脉冲 250 ms。
- 手动切回 Windows后重复一次，确认行为稳定。
- 再验证 Mac → Windows 一次。
- 最后进行 5 个完整往返即可。若无错误，不继续消耗时间做重复验收。

## 5. 故障注入

- Windows 离线或遥测超过 5 秒：ESP32 必须阻止需要 Windows 在线的完整模式切换。
- DDC 后端返回 false：结果为 `ddc_write_failed`，USB 不动。
- 命令处理超过 5 秒：ESP32 报超时，USB 不动；迟到结果不得引起 USB 动作。
- 结果中的 requested_input 故意错误：ESP32 拒绝，USB 不动。
- 收到重复 request ID：只发生一次 DDC 写入。
- ESP32 重启：客户端自动重连、重新 Hello，不自动切屏。
- Wi-Fi 断开再恢复：客户端按退避重连，不积压历史遥测。
- Windows 睡眠再唤醒：恢复连接，不自动切屏、不出现重复托盘图标。

## 6. 长期稳定性

功能验收完成后做一次 4 小时后台运行，观察内存、CPU、日志大小与重连。正式使用前可再做一次 24 小时自然运行，不要求持续人工操作。只有发现资源增长或随机断线时才进行针对性压力测试。
