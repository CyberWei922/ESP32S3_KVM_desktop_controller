# LCD BLK GPIO背光验证

这是从冻结版`v0.4.0-dev.3`复制出的临时验证工程，不属于`latest`正式代码。

## 操作

1. 屏幕按下表接线，将BLK接GPIO15。
2. 烧录本目录固件。
3. 屏幕正常显示后，短按中间按钮一次。
4. 确认背光是否完全熄灭，而不只是画面变黑。
5. 再短按中间按钮一次，确认背光能否恢复。
6. 记录串口中的`Physical backlight: OFF/ON`日志和实际表现。

启动日志必须包含`KVM Controller firmware 0.4.0-dev.3-backlight-test-r3`和`BACKLIGHT TEST R3 READY`。

中键接在GPIO5与GND之间，使用ESP32内部上拉，不需要外接电阻。左键GPIO4仍保留原继电器验证功能。

为避免原动态测试UI的大量逐像素SPI绘制触发CPU0任务看门狗，本专项固件只显示一次静态界面，之后仅更新三个按钮指示块。网络和按钮任务仍正常运行，但遥测文字不会持续刷新。

## 屏幕接线

| 屏幕针脚 | 名称 | ESP32-S3 |
|---:|---|---|
| 1 | GND | GND |
| 2 | VCC | 3V3 |
| 3 | CLK/SCL | GPIO12 |
| 4 | MOSI | GPIO11 |
| 5 | RES | GPIO14 |
| 6 | DC | GPIO9 |
| 7 | BLK | GPIO15（开漏控制） |
| 8 | MISO | GPIO13 |
| 9 | CS1 | GPIO10 |
| 10 | CS2 | 悬空 |
| 11 | PEN | 悬空 |

禁止把屏幕VCC接到5V。BLK实测接地电流约0.2mA，本测试直接接GPIO15；程序只使用开漏LOW和高阻释放，绝不推挽输出HIGH。

## 已确认的软件命令结果

实机多次发送`0x53 + 0x28`和`0x53 + 0x2C`后背光始终点亮。该模块不支持通过当前SPI接口关闭物理背光，本工程仅保留为验证证据。
