# 三键功能与交互设计

更新：2026-09-11。

本文记录控制器三个实体按键的当前功能定义。按键均由 ESP32-S3 读取，采用非阻塞消抖和按压时长判断。实体位置均按控制器正面从左到右描述。

## 1. 左侧按钮：屏幕电源、双机切换与状态校准

### 长按：屏幕开关

- 长按关闭或开启显示器与控制器 LCD 屏幕。
- 这里只改变显示状态，ESP32-S3 始终保持供电并继续运行网络、按键和控制任务。
- 关闭 LCD 时应停止不必要的屏幕刷新；是否能够控制背光，仍以 LCD `BLK` 引脚的实测结果为准。
- 关闭外接显示器时通过当前在线、活跃电脑的常驻程序发送 DDC 电源命令。
- 后续可以扩展“屏幕关闭后让 ESP32 进入离线或低功耗状态”，但不属于当前第一版功能。
- 长按动作只触发一次，持续按住不得反复开关。

### 单击：显示器与 USB 联动切换

- 系统只有 Mac 和 Windows 两台设备，因此短按执行当前目标的二态翻转：Mac → Windows，或 Windows → Mac。
- 执行前必须确认目标设备在线。目标设备离线时拒绝切换，显示失败原因，并保持当前显示器输入、USB 推定归属和内部状态不变。
- 切换请求由当前活跃电脑执行 DDC，以适配 KOORUI X41Q 只有当前活跃输入链路能够可靠发送切换命令的特性。
- DDC 请求必须携带唯一 `request_id`。重复请求不能重复执行显示器切换或 USB 继电器脉冲。
- 只有显示器 DDC 写入成功后，才允许向 USB 共享器继电器发送一次切换脉冲；DDC 失败时不得切换 USB。
- USB 继电器动作后，同时更新显示器目标状态和 USB 推定归属。由于两者暂时都缺少可靠硬件反馈，界面不得把推定状态显示成已物理确认。
- 一次切换开始后进入至少 5 秒冷却期。冷却期内忽略新的切换短按，防止显示器换源期间重复动作造成状态错乱。
- 切换超时、电脑掉线或结果不明确时退出切换流程，不自动翻转内部主机状态，并提示人工检查或校准。

### 双击：交换推定状态以校准

- 当实际显示器/USB所在主机与 ESP32 保存的状态相反时，双击左侧按钮，将内部推定状态在 Mac 和 Windows 之间交换。
- 双击校准只修改 ESP32 保存的当前主机和 USB 推定归属，不发送 DDC 命令，也不触发 USB 共享器继电器。
- 校准后屏幕应明确显示新的推定状态，并短暂显示“状态已校准”，避免用户误以为发生了物理切换。
- 系统只有 Mac 和 Windows 两个状态，因此不需要进入多级校准菜单。
- 如果未来显示器输入与 USB 归属可能分别错位，应再提供分别校准两者的维护入口；当前第一版按两者同步交换处理。
- 为区分单击和双击，首次松键后需等待一个较短的双击判断窗口，确认没有第二次点击后才执行单击切换。初始建议窗口为 300 ms，最终以实测手感确定。
- 双击判断窗口内以及双击完成后，不得误触发单击切换。

### 当前建议状态机

```text
空闲
  → 确认为单击
  → 检查目标设备在线
  → 检查当前执行 DDC 的设备在线
  → 发送带唯一 request_id 的 DDC 命令
  → DDC 写入成功
  → USB 共享器继电器单次脉冲
  → 更新推定状态
  → 进入 5 秒冷却
  → 返回空闲
```

任何在线检查或 DDC 步骤失败，都直接返回空闲，不触发 USB 继电器。

## 2. 中间按钮

中间按钮预定为 LCD 数据页面切换键，使小屏幕后续可以容纳更多状态和控制信息。

### 单击：循环切换数据页面（后续启用）

- 每次单击切换到下一个已经注册的 LCD 页面。
- 到达最后一页后返回第一页，形成循环翻页。
- 首批系统暂不启用翻页功能：保留 GPIO、接线、消抖和按键事件接口，但按下后不改变页面，也不执行电脑操作。
- 后续增加页面时，不在按键代码中直接编写各页面业务；按键只产生 `PAGE_NEXT` 事件，由统一页面管理器决定下一页并请求 UI 刷新。
- 翻页只改变本地 LCD 显示，不影响 WebSocket 连接、遥测采集、KVM 当前主机、USB 推定归属或散热模式。
- 页面刷新必须非阻塞，后台网络、温控和按键扫描任务持续运行。

### 预定页面路线

```text
系统总览
  → Mac 详细状态
  → Windows 详细状态
  → KVM/USB 状态
  → 散热器状态
  → 系统总览
```

实际首批页面仍由后续 UI 开发决定；未实现的页面不得加入循环列表。

### 双击与长按

当前不分配功能，保留给后续扩展。首批固件不得因为双击或长按中间按钮执行隐藏操作。

## 3. 右侧按钮：Mac 散热模式

### 短按：循环切换模式

每次短按按以下顺序循环：

```text
标准模式 → 静音模式 → 性能模式 → 标准模式
```

当前目标温度定义为：

| 模式 | 目标温度 |
| --- | ---: |
| 标准模式 | 30°C |
| 静音模式 | 35°C |
| 性能模式 | 25°C |

- ESP32 根据 Mac 上报的 CPU 温度和当前目标温度，以类似 PID 的闭环思路决定散热器档位。
- 散热器只有离散档位，并通过继电器模拟原按钮，因此实际控制应采用分档控制、温度平滑、回差和最短保持时间，不能直接照搬连续 PWM PID 输出。
- 继电器通过单击、双击或长按时序模拟散热器原按钮；具体脉冲宽度、双击间隔和长按时间以实测为准。
- Mac 离线、温度无效、温度数据过期或散热器档位未知时，暂停自动调档，不使用旧温度继续控制。
- 当前模式写入 NVS，ESP32 重启后恢复；屏幕始终显示当前模式、目标温度及散热器的推定档位。
- 模式刚切换时不应立即连续发出多次继电器动作，应由温控状态机按最短调档间隔逐级接近目标档位。

### 长按

当前尚未定义，预留给散热器开关或档位校准功能。

## 4. 尚待实测的参数

- 单击、双击与长按的时间分界和双击判断窗口。
- 左侧按钮控制 X41Q 关闭后，DDC 是否还能将显示器唤醒。
- USB 共享器继电器的可靠脉冲宽度和上电默认状态。
- 散热器单击、双击、长按的可靠时序。
- 散热器四档边界、上电默认档位和断电记忆行为。
- 三种温控模式的目标温度是否以实际 CPU 传感器读数为准，以及各模式所需的回差、平滑窗口和最短保持时间。
