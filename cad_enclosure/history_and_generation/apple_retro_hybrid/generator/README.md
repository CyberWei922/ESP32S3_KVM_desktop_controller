# Apple 复古混合式桌面控制器 V119

更新：2026-09-11。单位均为毫米。坐标约定为 X=左右、Y=前后、Z=上下，负 Y 为使用者正面。

V119恢复上舱底板的走线开口，并与下层底座顶板现有开口共用同一组36 × 22 mm、圆角3 mm、中心X=0/Y=22 mm参数。上下两个开口现在投影完全重合并贯穿装配接缝。V117的定位槽、定位环和5条后盖散热孔全部保留。V117快照保存在`releases/Apple_retro_hybrid_v117_2026-09-10.zip`。

## 当前打印件

`cad_enclosure/latest_output/apple_retro_hybrid/`中保存V119当前输出：

1. `01_lower_base_body.stl`：下部底座主体，包含三键卡槽、三组后接口结构、上下层定位槽、四个连接孔和36 × 22 mm走线开口。
2. `02_inset_bottom_cover.stl`：内嵌底盖，包含四颗对称沉头孔、脚垫槽、按键固定器后挡片和中央Type-C板平面压台。
3. `03_upper_shell.stl`：前后开放的渐缩上舱，前部保留圆角，后部左右外角改为45°平面，并包含后盖开口四边45°倒角框、顶部提手、顶部/侧面散热孔、上下层定位环、M3螺母槽、与底座完全对齐的36 × 22 mm走线开口和前后面板安装结构。
4. `04_upper_front_panel.stl`：由主壳母体表面切出的齐平斜置前盖，包含隐藏定位舌、CRT式深屏幕斗、LCD窗口、软驱装饰槽、凹刻Apple标志和LCD固定柱。
5. `05_upper_back_cover.stl`：完整直边独立斜置后盖，包含5条上方散热孔、拆盖指槽、四个固定孔和50 × 70洞洞板固定柱；散热孔与柱体互不相交，盖板本身不承担外观倒角。
6. `06_fastener_fit_coupon.stl`：正式打印前使用的M3自攻底孔与普通六角螺母槽公差试片。

前五件组成完整外壳；第六件只用于选择代打印机的实际孔径公差。

## 五件式连接

### 上舱与底座

- 86 × 50隐藏圆角定位环进入底座同形槽，每侧约0.35装配余量；定位环承受横向力。
- 四组孔位X=±34、Y=8/36，避开后方两块接口PCB。
- 从拆下底盖后的底座内部向上装入4颗M3机牙螺栓，上舱使用普通M3六角螺母。
- 六角槽对边5.8、深2.8；上下舱各有一个36 × 22、圆角3的隐藏走线孔，两孔中心均为X=0、Y=22，装配后完全重合。

### 前面板

- 前盖和上舱前壁刚性后仰6°；螺丝轴线、LCD固定柱和屏幕斗均垂直于前盖。前盖自己的2.5 mm、约45°外缘负责唯一的倒角视觉。
- 前盖与主壳由同一个外壳母体沿Y=5.5的隐藏分件面切开，外观间隙为0；侧面斜度和圆角在接缝两侧连续。2.6深定位舌位于壳体内部，四边单边留0.25 mm，不会在外面形成边框或台阶。
- 两颗隐藏M3塑料自攻螺丝从上舱内部向前锁入面板盲孔柱；拆下后盖即可操作。
- LCD使用四颗M2.5塑料自攻螺丝固定，正面没有螺丝。

### 后盖

- 上舱后方最外侧左右圆弧已经改成平面45°切角；配合原有上下45°面，后方外轮廓四边角度一致。
- 后盖开口的上、下、左、右四边均由机身形成2.5 × 2.5 mm、45°倒角，直角拼接处不使用圆弧过渡。
- 倒角后方设有与机身连成一体的承口框；后盖是完整直边梯形板，随上舱后壁向前倾斜并位于承口框内缘，四周实际法向间隙0.25 mm，盖板自身不包含外观倒角。
- 四颗M3塑料自攻螺丝固定到上舱柱体，孔、柱和螺丝轴线都垂直于后盖。
- 固定孔X=±37、Z=37/125；柱体与面板之间保留0.25轴向装配间隙。
- 洞洞板安装在后盖内侧，拆盖后可整体维护ESP32、继电器和线束。

### 底盖与按键固定器

- 四个底盖孔完全对称：X=±46、Y=±39。
- 后部机箱连接台保持水平；前部键盘台从按键浅槽后缘的折线开始向使用者方向下降7°。固定器从底部开口后侧沿该斜面滑入，左右和前侧定位，前后两条同角度承力轨承担按压载荷。
- 底盖挡片以相同7°封闭唯一入口；承力轨避让槽仍保留44宽挡止面，挡片底部由隐藏加强台连接水平底盖。

## 紧固件公差试片

先用正式件相同材料、喷嘴、层高和墙数打印`06_fastener_fit_coupon.stl`：

- 左侧三孔：直径2.5 / 2.6 / 2.7的M3塑料自攻底孔。
- 右侧三孔：对边5.6 / 5.8 / 6.0的M3普通六角螺母槽，均带M3通孔。

实物试片结果为：2.5和2.6 mm底孔过小，2.7 mm可以正常攻丝；5.8 mm螺母槽配合合适。V119正式模型因此使用2.7 mm M3自攻底孔和5.8 mm螺母槽。

## 代打印参数

- 优先优质PLA+、Tough PLA或哑光PLA+，颜色选奶油白、象牙白或复古米白。
- 0.4喷嘴；主体0.16层高；前面板屏幕斜面可用0.12～0.16可变层高。
- 至少4圈外墙，螺丝柱附近5～6圈，15%～20%填充。
- 底座底面向下；底盖平放；前面板保护正面；上舱优先以后口朝下试排支撑。
- 首次攻丝使用手动螺丝刀，不使用电动工具直接拧到底。

## 生成与验证

```bash
.cadenv/bin/python cad_enclosure/history_and_generation/apple_retro_hybrid/generator/generate_hybrid.py
.cadenv/bin/python cad_enclosure/history_and_generation/apple_retro_hybrid/generator/render_preview.py
```

生成器会清理`latest_output/apple_retro_hybrid/`中的旧STL并写入V119六个当前文件。预览脚本会生成装配图、爆炸图、中央Type-C夹持剖视图和后部外缘/开口倒角拆盖对照图；预览中的LCD、固定器、三个键帽及Type-C板材只是展示现有硬件位置，不会输出为打印件。

生成后必须确认每个STL均为封闭、绕向一致、单一连通实体，并检查五个装配件之间没有正体积干涉。最终线束、天线和完整洞洞板布局仍需收到实物参数后再冻结。
