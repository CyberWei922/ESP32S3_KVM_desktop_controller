# 当前版本

- 当前版本：`v0.5.0-dev.22`
- 日期：2026-09-17
- 状态：新增天气、行情、状态三页仪表盘；ESP32与Mac端已编译，等待刷写和三端实测
- ESP-IDF：保持v6.1
- 目标芯片：ESP32-S3-N16R8
- UI：使用 LVGL 9.3.0，当前页面为 SYSTEM、WEATHER、MARKETS
- 显示：ILI9341，320×240横屏，非触摸

## 本版变更

- 中键单击/双击分别切换下一页/上一页，页面为SYSTEM、WEATHER、MARKETS。
- 新增`dashboard`协议消息，天气包含当前、未来三天和未来五个整点；行情包含BTC、DOGE与USD/CNY。
- Windows为主数据源，30秒无数据后允许Mac接管；Windows恢复稳定60秒后自动夺回主数据源。
- ESP32只缓存与显示数据，不直接访问互联网；外部数据异常时保留最后快照并显示错误。
- 天气图标由LVGL本地彩色像素图元绘制，不依赖网络图片。

- Live Data增加当前主机标记、20格内存进度条和整数`°C`温度格式。
- 散热器面板改为档位、像素风扇、目标温度和模式四项核心信息。
- GPIO8启用独立散热器控制任务，支持Manual、Standard、Silent、Turbo模式。
- 第三按钮支持单击、双击、500–999ms模式切换和1秒关机判定。
- 启用上电档位归一化，以及带平滑、回差、持续确认和最短保持时间的自动调档。
- 模式和三个自动模式的目标温度写入NVS。
- 实机调整：散热器模拟长按延长至2秒，上电校准的三组双击组间隔延长至1秒。
- 实机调整：散热器单击闭合延长至120ms；双击内部脉冲保持70ms。
- `hello`增加可选能力协商，兼容protocol v1旧客户端。
- 左键长按熄灭ESP32背光时，分别请求Mac与Windows停止显示输出。
- 熄屏期间注销全部按钮，仅保留左键长按唤醒；唤醒只恢复关屏前的当前画面主机。
- 切换到仍处于休眠输出状态的另一台主机前，先请求目标主机恢复输出，再执行既有DDC与USB流程。
- Mac/Windows未升级、掉线或命令失败时保留安全错误状态，不把失败误报为显示器已休眠。

## 版本边界

- protocol v1保持与`../../StatsForKVM/PROTOCOL.md`兼容。
- GPIO15开漏背光控制已通过实机验证；LOW关闭，高阻开启，禁止推挽HIGH。
- 散热器双击和关机闭合时长仍是首轮实测参数，集中定义于`main/include/app_config.h`。
