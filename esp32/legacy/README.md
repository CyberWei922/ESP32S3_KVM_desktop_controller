# ESP32历史版本

本目录保存已经冻结的ESP32版本。历史版本只用于回退、对照和提取经过验证的实现，不在原目录继续修改。

| 版本 | 说明 |
| --- | --- |
| `v0.1.0` | 早期基础版本 |
| `v0.2.0` | 早期显示开发版本 |
| `v0.2.1` | 显示修订版本 |
| `v0.3.0` | ILI9341最小可运行冻结版 |
| `v0.4.0-dev.1` | Wi-Fi/WebSocket开发基线 |
| `v0.4.0-dev.3` | 2026-09-12全链路验证基线，LVGL重构前最终测试版 |

私密Wi-Fi配置和包含凭据的构建产物不进入历史版本。需要构建时使用本地配置重新生成，不复用来源不明的二进制。
