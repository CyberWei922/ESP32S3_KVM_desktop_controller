# v0.4.0-dev.3 验证基线

- 日期：2026-09-12
- 状态：用户确认硬件全链路验证成功，作为 LVGL 重构前的最后一版测试固件冻结。
- ESP-IDF：v6.1
- 目标芯片：ESP32-S3-N16R8

## 已验证能力

- ILI9341 320×240 横屏显示和原测试 UI。
- GPIO4、GPIO5、GPIO6 三个机械按键，内部上拉、按下接地、30 ms 软件消抖。
- 屏幕三个按键方块反馈。
- GPIO7 高电平控制 YS-HK1 继电器，左键按住时闭合、松开时释放。
- GPIO8 高电平控制第二块YS-HK1继电器，右键按住时闭合、松开时释放，用于散热器专用Type-C按钮链路测试。
- Wi-Fi Station、WebSocket protocol v1、多客户端状态模型、遥测过期与断线处理。
- macOS StatsForKVM 遥测和显示器 DDC 命令链路。
- 用户确认继电器供电、触发和 COM/NO 输出链路工作正常。

## 冻结说明

- 本目录仅用于回退、核对和移植已经验证的底层实现，不再继续开发。
- 新版从 `esp32/latest/` 开始，以 LVGL 完全重构 UI。
- 私密 Wi-Fi 配置没有进入本目录，保存在被忽略的 `esp32/kvm_config.local.h`。
- 原来可能包含 Wi-Fi 凭据的构建产物未归档；如需二进制，应在无私密配置状态下重新构建。
- 协议的权威定义仍为 `StatsForKVM/PROTOCOL.md`。
