# v0.4.0-dev.3-backlight-test-r3

- 类型：临时背光软件控制验证固件。
- 基线：`esp32/legacy/v0.4.0-dev.3`；冻结归档未修改。
- 目的：验证ILI9341V的`Write CTRL Display (0x53)`能否通过模块内部连线控制物理背光。
- 操作：每次按下GPIO5中键，在参数`0x28`（请求关闭）与`0x2C`（请求打开）之间切换。
- 本测试不连接BLK，不增加背光GPIO或MOSFET。
- 专项版本禁用原测试UI的持续遥测重绘，只保留静态画面和按钮指示，避免逐像素SPI绘制阻塞CPU0空闲任务。
- R2将轻量按钮任务命名为`bl_button_test`并固定到CPU1；启动成功必须显示`BACKLIGHT TEST R2 READY`。
- 实测BLK接地电流约0.2mA；R3改为GPIO15开漏直接控制BLK。LOW关闭背光，高阻释放开启背光，禁止推挽输出HIGH。

## 结果判定

- 背光完全熄灭并可再次点亮：模块已连接芯片内部背光控制输出。
- 画面停止或变黑但仍有白色背光：软件命令没有关闭物理背光。
- 完全没有变化：该模块没有使用ILI9341V的LEDON/LEDPWM输出。

## 实机结果

- 2026-09-12：中键多次切换均成功输出`53h=28`与`53h=2C`日志，物理背光始终点亮。
- 结论：本模块PCB没有让ILI9341V软件背光输出控制物理背光；正式设计不得依赖`0x51/0x53`背光命令。
- 下一步只评估BLK外部开关或模块VCC电源开关。
